# Tibetan Calculator Privacy Policy

Static privacy-policy website for Tibetan Calculator. It is ready to host with
GitHub Pages and does not require a build command or external dependencies.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Push this folder to the repository's `main` branch.
3. Open **Settings → Pages** in the GitHub repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

The published URL will normally be:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Local preview

Run a static web server in this directory, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.
